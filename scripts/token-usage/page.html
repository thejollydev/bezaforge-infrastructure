      What this teaches

      If you ever pay by the token

      The price of a session depends mostly on how long it runs and how large the conversation grows, not on what the task is. These are the levers, roughly in order of size.

      • End sessions between unrelated tasksA fresh session starts from a few thousand tokens instead of two hundred thousand. Every later step is cheaper for it.
      • Pick the model per sessionRe-reading costs $0.50 per million tokens on Opus 5 and $0.20 on Opus 5.5, so the same session costs noticeably less on 5.5. Sonnet 5 is $0.20 too, with cheaper writes and output.
      • Send heavy reading to subagentsA subagent reads in its own conversation and hands back a summary, so the main conversation stays small. Subagents were only of this month.
      • Output is the small partWhat Claude writes was about a tenth of the cost. Asking for shorter answers helps less than keeping the conversation short.
      How this was counted

      Method and limits

      Every assistant message in ~/.claude/projects/**/*.jsonl records its model and its token counts. Repeated lines were removed by message and request id, and subagent transcripts are counted with the session that started them. Each token type is priced at its own rate from the Anthropic pricing page as fetched on ; web searches at $10 per thousand. Days are local ().

      This is what current habits would cost at list prices, not a quote. Paying per token would change the habits. Subscription usage limits are not in the transcripts, so this page cannot show how close any week came to them. Codex is priced at OpenAI's list rate for gpt-5.6-sol ($4 input, $0.40 cached input, $20 output per million tokens); its generated images are billed separately by OpenAI and are not in its logs, so they are not counted. Antigravity keeps no comparable record and is not included.

      Claude Code deletes transcripts after cleanupPeriodDays in its settings, 30 by default. Raise it to keep the history this report reads.
